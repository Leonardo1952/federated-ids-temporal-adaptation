# Provenance of this distribution

This is an organized software distribution derived from the original experimental implementation. The campaign executable, its GO, entry attestation and sealed outputs remain in the author's research archive. The source was reorganized and some public-facing names and paths changed. It must not be described as a byte-identical copy of the campaign executable.

The original v4 campaign processed 160 positions: 150 complete runs and ten authorized scientific terminations, with no technical failures in v4. The ten TON global Page–Hinkley contrasts are not evaluable on the full horizon. The definitions of the primary endpoint and descriptive scope are preserved in [the analysis plan](../analysis_plan.md) and [the scope decision](../descriptive_scope.md).

The initial publication omits all data-derived binary and numeric artifacts whose redistribution has not been established. Its [`artifacts/MANIFEST.sha256`](../../artifacts/MANIFEST.sha256) identifies only files actually shipped under `artifacts/` and `configs/`; it is not the original campaign manifest. Copying the code into this repository changes Git identity. Operational guards and authorization checks remain in place, so historical approvals cannot be reused.
